03 · Algorithm selection + automatic switching

Requested: AUTO Effective: —

Auto starts with Round Robin, uses SJF for mixed-size jobs under moderate load, and Adaptive for stress or failures.

Auto thresholds: server estimated utilization ≥ 80%, network utilization ≥ 75%, or unavailable server → Adaptive. After six calm checks, return to SJF for mixed-duration jobs or RR otherwise. SJF sorts waiting jobs at each TCP server by the requested work time. Decisions affect new TCP flows, not established connections.

06 · Failure: one host unresponsive

Pause Server 2 while keeping its process alive. This removes heartbeats and allows the controller to detect a timeout.

Expected: heartbeat timeout should mark srv2 unavailable. Adaptive avoids it for new flows. Existing in-flight requests may fail; a fresh client retry can be redirected. This is different from keeping an established TCP connection alive.
